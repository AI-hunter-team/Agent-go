# 角色资产

`dafeiyu.glb` 为用户在 AVATAR-001 后续提供的“行走大肥鱼.glb”，替换此前的默认主角。文件原样复制，SHA256 在任务验证报告追加记录；为带 65 根 Mixamo 骨骼、蒙皮和内嵌贴图的 Tripo glTF 2.0 导出，文件没有动画片段。应用运行时生成站立及行走骨骼动画，驱动双腿、膝盖、脚踝、手臂和躯干；旧文件的 11 段动画属于历史资产，不适用于当前文件。

`naiwa.glb` 为用户提供的原始“奶娃”，保留作为模型制作输入。新附件 `cute blob creature 3d model.glb` 与它的 SHA256 相同。原文件含蒙皮、骨骼与内嵌贴图，没有动画片段。

`naiwa-security.glb` 是游戏当前默认保安的独立完整模型，由 `scripts/build-security-guard.ts` 生成。保留原始贴图与蒙皮，新增深蓝帽冠、黑色帽檐、金色原创帽徽和右手警棍。帽子按初版缩小 12%，绑在头骨；警棍绑在右手骨。文件内嵌 `Idle` 待机观察（4.2 秒、左右约 29° 转头）和 `Walk` 巡逻步态（1 秒），在其他支持 glTF 动画的查看器中也可播放。两名保安分别克隆模型，巡逻与视野规则不变。

重建命令：`npx tsx scripts/build-security-guard.ts`；默认从原始 `naiwa.glb` 读取并输出 `naiwa-security.glb`，不会覆盖原始文件。

当前警棍采用日常巡逻低持：前臂与手腕放松，四指及拇指包握手柄，棍身斜向下；握持手型烘焙进两段动画，警棍跟随右手。

运行时自动居中、脚底对齐并适配约 1.7 米高度；按动作名选择动画。其他自定义模型从“显示设置 → 主角模型 / 保安模型 → 导入模型”选择，不放入此目录，不上传服务端。

主角与保安自带行走片段时优先播放原动画；没有行走片段且具备可识别的 Mixamo 双腿/手臂时，生成原地步态与放松站姿。动画随行走状态、暂停/思考及倍速切换，不产生世界位移。其他骨架命名不保证自动适配。大肥鱼的生成动画只在运行时使用；奶娃保安的动画已烘焙进独立 GLB。

自定义导入支持自包含的 GLB 2.0，每个最大 20 MiB；外部贴图/缓冲区和需额外解码器的压缩格式不在本次支持范围。浏览器 IndexedDB 分别保存主角和保安的模型与朝向，清除站点数据会删除该设置。
