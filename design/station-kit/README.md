# agent-go：非角色站厅素材小样 V2

这是可复用的三维资产包与独立预览。基础V2库保留27类/33GLB及9张512×512贴图；当前正式场景和样板间另外载入中国地铁A圆管/B玻璃栏杆7GLB，旧3类密竖杆仅作兼容数据，选择器显示31类现用模块。角色由用户另行提供。原接入见 [STATION-INTEGRATION-001](../../docs/tasks/STATION-INTEGRATION-001.md)，6米层高与楼梯见 [STATION-DISPLAY-001](../../docs/tasks/STATION-DISPLAY-001.md)，新栏杆见[素材说明](../metro-railings/README.md)与[当前验证](../../docs/validation/METRO-RAILING-001.md)。

## 查看交付包

解压后运行 `start-preview.cmd`（需要 Node.js），打开控制台显示的本机预览地址。也可在包根目录执行：

```sh
node serve.mjs preview 5191
```

预览默认是 1.62m 眼高的室内视角；可切换拼装总览、单模块查看和六种材质球。圆角赭黄结构框、顶板、嵌入灯带、窗侧光、面积补光、柔化地面反射和接触阴影组成空间氛围。反射与接触阴影属于预览渲染，后者可关闭；不是模型中烘焙的光照。

可切换直线/左右分流/绕柱布局、设备开放/停用/故障、双翼闸机开合，下载所选状态的 GLB。预览实际加载交付 GLB，不以工厂内存模型代替导入验证。

- 成品：`preview/assets/station-kit/models/`
- 独立贴图：`preview/assets/station-kit/materials/`
- 文件大小、SHA256、尺寸、三角面、材质槽和交互锚点：`preview/assets/station-kit/manifest.json`
- 来源说明：`preview/assets/station-kit/sources.json`
- 生成源文件：`source/`；按完整项目的相同路径保留，可在项目依赖下重建。

## 模块和尺寸

| 类别 | 模块 |
|---|---|
| 地面 | 暖白磨石、鼠尾草绿磨石、素色地面 |
| 建筑 | 直墙、L 转角、端头、门洞、方柱、低隔断 |
| 高顶系统 | 6m 跨度圆角框、3m 顶板、2.2m 灯带、3m 窗墙、2.5m 高侧封板 |
| 设施 | 售票机、安检门、双翼闸机，各有开放/停用/故障版 |
| 导视 | 空白导视柱、空白悬挂标牌、独立箭头、排队标线 |
| 连续导向 | 3m 直段、圆弯、T 型分流；0.46m 漆带，独立于地板 |
| 旧固定栏杆（兼容） | 3m直段、1.5×1.5m转角、端柱；高1.1m、柱脚0.16m、密竖杆；不再用于当前场景 |
| 中国地铁栏杆（独立清单） | A圆管双横杆/B玻璃各含直段、转角、端柱，另有B斜段；详见[尺寸与装配](../metro-railings/README.md) |

单位米，Y 向上。根节点位于占地中心的地面；地面模块顶面为 Y=0、底面为 -0.12m。通用建筑模数 3m，基础墙高 3.5m，墙厚 0.4m，方柱占地 2×2m、高 5.95m。柱饰面略超出 2m 原始结构包络，最终碰撞仍由模拟器给定。

顶板安装面为6m，源结构框和方柱高5.95m，基础墙上方用2.5m侧封板补齐。建筑高度共用 `src/assets/station-kit/dimensions.ts`；结构框源几何保留原有梁厚与圆角，不整体拉伸站厅。顶板/灯带的Y=0表示安装面，不表示地面。正式场景按当前70×30m地图拼装，下层站台地面为-2m，总览隐藏顶面与外围上部构件。

正式场景全部平层地面与楼梯踏面统一采用样板间鼠尾草绿磨石。两处共用低透明度柔和反射，正式场景在上下层分别设置反射面、排除楼梯开口并在反射通道隐藏全部反射面以避免递归。标准跟随视角开启，低画质和总览关闭；仍按原调度按需绘制与限帧，不额外启动动画循环。

入口门洞上沿接至6m顶板，横梁保持原厚度，通行净高为5.25m，避免旧低门楣遮住站厅视野；净宽仍为2m。

正式场景的程序楼梯沿用鼠尾草磨石，9m长/4m宽/2m落差细分为20级，具有深灰防滑凹槽、圆角踏鼻、封闭侧面/底面与平台收口；构造在 `src/ui/scene/staircase.ts`，不新增楼梯GLB。当前已串行接入B玻璃护栏，底座落到各级踏面、入口角柱共用；A圆管用于安检和闸机隔断。

动态悬挂导视文字与设施编号使用同一绘制函数，纹理像素比例匹配最终世界空间显示面；长文字等比例缩小字号，不使用 Canvas 的横向 maxWidth 压缩。安检门立柱在横梁下缘结束，保留2.5m整体高度、净宽、状态灯与锚点，消除原顶部重叠面；三种状态GLB已同步重新生成。

设施正面为本地 +Z，玩家从 +Z 接近，出口在 -Z；接入现有 -X 朝向的站厅时绕 Y 旋转 -π/2。地面箭头指向本地 -Z。场景已有设施锚点和碰撞规则是权威，GLB 外观和元数据不自行改变通行规则。

正式接入将安检门净宽校准为2m、闸机净宽约1.02m；售票机沿世界+X平移0.264m，使可见前缘保持原有位置。设施逻辑坐标、队首和服务出口不移动。安检输送带由同一材质组成，实体占地与模拟器共用纯数值定义。

旧 `fitRailingSpan` 与原3类栏杆保留作兼容数据。当前使用 `fitMetroRailingSpan` 装配A圆管/B玻璃，保持杆径、固定底座与夹具尺寸，支持共用端柱和玻璃斜段；连接基准和正式踏面落脚规则见[新栏杆说明](../metro-railings/README.md)。栏杆依然阻挡通行而允许视线通过，模拟器规则未变。

材质颗粒按每 3 米纹理周期生成；不同尺寸的结构使用米制 UV，避免把颗粒随物体拉伸。墙面、地面和喷涂共享三组基础贴图，使用材质颜色区分暖白/鼠尾草/赭黄/炭黑。砖红导向使用参数材质。

导出器读取工厂材质的 `userData.maps` 并将贴图内嵌到 GLB。直接调用工厂获得的是几何与参数材质；实际使用优先载入成品 GLB，或按清单绑定贴图。

## 活动部件和状态

- 每个闸机保留 `flap_left` / `flap_right` 铰链组；`userData.role=gateHinge`，`sign` 为 -1 或 +1。角度为 `sign × progress × π × 0.48`，progress 为 0–1。
- 设备灯带标记 `statusIndicator`，屏幕标记 `statusScreen`；状态为 `open` / `closed` / `broken`。带材质的静态状态版可直接导入，源代码也提供状态切换方法。
- `anchor_interaction`、`anchor_entry`、`anchor_exit` 为模型局部参考；售票机没有穿行出口。排队间距与地图锚点继续由模拟器负责。
- 标牌文字和编号在预览中动态绘制，不烘入 GLB，地图改变时可以替换。闸机为程序驱动铰链，没有烘焙角色动画。

## 在完整源码仓库重建

使用项目 npm 锁定依赖：

```sh
npm ci
npm exec tsx -- scripts/station-kit/build.ts
node node_modules/vite/bin/vite.js --config design/station-kit/vite.config.ts
```

导出目录是 `public/assets/station-kit/`，开发预览端口为 5190。可选环境变量 `KIT_TEXTURE_SIZE` 为 128 / 256 / 512 / 1024，默认 512。同样源代码、种子和配置应生成同样的二进制。

构建可分发的预览：

```sh
node node_modules/vite/bin/vite.js build --config design/station-kit/vite.config.ts
```

输出 `dist/station-kit-preview/`。它由普通静态服务器运行，避免 file:// 下的模块和资源加载限制。独立预览默认期望部署在该静态服务的根路径。

当前仓库忽略 PNG、ZIP 和构建输出；贴图可重建，交付包中已包含。评审应保留源代码、清单与验证记录；不强行更改根忽略规则。

## 验证与限制

资产校验脚本为 `scripts/station-kit/validate.mjs`，参数为独立安装的 Khronos `gltf-validator` 目录及可选报告文件；不把校验工具添加到业务依赖。浏览器检查脚本接受 Chrome 可执行文件、证据目录和可选预览 URL。

原 V2 的验证快照保留在 `docs/validation/ASSET-KIT-001-V2.md`；新增栏杆与正式游戏接入见 [当前验证](../../docs/validation/STATION-INTEGRATION-001.md)。独立预览的三种拼装样例用于视觉复用检查。正式场景缓存 GLB、共享材质并批量绘制重复部件；设备独立更新状态与铰链。资源失败时显示几何场景和提示，可重建三维画面重试。角色正式美术、真实模型整局和硬件性能属于后续验收。

程序生成几何与纹理不含第三方艺术资产。分发授权遵循项目授权决定，本包不额外授予未确认的独立授权。Three.js 代码依赖沿用其自身许可证。
