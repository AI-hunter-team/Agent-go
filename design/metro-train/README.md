## 游戏中的停站展示

- 正式 `GameScene` 挂载 `MetroPlatform`，独立于站厅素材加载器，实际读取同一车头车 GLB。
- 车体位于既有可行走站台的东侧，沿 Z 轴停靠；原始比例保持 1:1，展示首节可视段，不把它宣称为真实完整编组。
- 站台高程 -2m，轨面 -3.1m，车内地板对齐站台；车身与站台边界间隙约 0.16m。只打开面向站台的 10 片门扇，对侧保持关闭。
- 配套轨道、站台边缘、安全线、盲道、端部暗口和停靠导视；总览隐藏轨道顶棚，便于查看列车。
- 停站门姿态合批为 14 个材质网格；源码和独立预览仍保留原有可操作门节点。
- 该接入不增加上车/到发动作，仍由模拟器结算下楼到站台的成功结果。列车文件失败仅显示资源提示，现有“重试素材”可以恢复。

在接入工作区执行 `npm run dev` 可按根 README 启动；需要隔离本机其他开发实例时，分别指定 API 端口与 Vite 端口。此次交付的独立游戏预览为 5204，API 为 8894，均仅监听本机。

## 设计方向与实车参考

银白金属车身、石墨色前窗、青绿色腰线和短车头；细节适度简化，轮廓保持真实尺度。青绿色是本项目选择，不冒充某个真实线路的涂装。

| 参考 | 使用范围 |
|---|---|
| [中车：中国标准 A 型地铁 / 广州11号线](https://www.crrcgc.cc/zj/2025-01/06/article_2025010615113095490.html) | 中国城市地铁的短车头、大前窗、独立车灯与简洁客室方向；原车南狮/金色元素不照搬 |
| [中车：中国标准 B 型地铁发布](https://crrcgc.cc/pz/2023-08/04/article_30174B96C76E4BF186517B4E720C420E.html) | 中国标准地铁平台、通透客室与不同车宽分类；B 型宽度不套作 A 型精确规格 |
| [上海14号线实车照片报道](https://ishare.ifeng.com/c/s/7pt2sqfz9QL) | 仅观察银白/深色前窗/绿带的视觉关系；不采用其照片或商标作为资产 |

本模型为原创几何，不是实车工程图、精确复刻或完整制式规范。车长、门位、灯具及线路名称由游戏小样设计，不据此宣称对应真实型号。

## 使用

在仓库根目录，已有依赖时执行：

```sh
npx tsx scripts/metro-train/build.ts
npx vite --config design/metro-train/vite.config.ts
```

无依赖先 `npm ci`。生成输出位于 `public/assets/metro-train/`。预览使用 GLTFLoader 读取实际 GLB；支持车头车、中间车、三车示意、车头近景和侧面视角，以及双侧车门开合与线路色切换。

## 尺寸、节点与接入

- 米制，Y 向上、车头 +X；原点是车体纵横中心的轨面投影，轨面 Y=0，客室地板 Y=1.1。
- 小样车长 22.8m、车体宽 3m；车顶及受电弓高度由清单记录。模型保持比例，正式车站仅展示部分编组。
- 两种独立 GLB：车头车、中间车；尾车由车头车旋转 PI。预览三车属于查看连接效果的示意，非实车完整编组。
- 门节点 `userData.role=metroDoor`，以 `closedX`、`travel` 计算 `position.x`，门均独立分组；开度 0–1。
- 线路色材质名 `metro.line.*`，更换材质颜色即可换线；玻璃与金属、胶条分别使用独立材质。
- `anchor_*` 给出地板、端部连接与门口锚点。锚点只供资产摆放，不改变模拟世界。
- 复用现有站厅 GLB 写入器，文件的生成器字段沿用该工具名；资产身份、源文件与参考来源以本包清单为准。

## 本轮讨论重点

1. 车头希望更圆润还是更有棱角？
2. 青绿腰线的宽度与前脸覆盖范围是否合适？
3. 透明车窗与可见内饰的细节程度是否适合现有站厅？
4. 外观确认后再确定站台轨道位置、屏蔽门及列车到发演出。
