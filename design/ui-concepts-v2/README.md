# 第二轮：两天原型范围内的三种轻量 3D 风格

状态：历史视觉探索，技术与原型建议不替代当前产品基线；见 [文档导航](../../docs/README.md)。下文图片均未入库，文件名仅保留为历史索引；原始提示词见 [PROMPTS](PROMPTS.md)。

日期：2026-10-30。本轮使用内置 imagegen 生成概念图，未开发实际网页。上一轮 B、C 的资产、光影与动画复杂度不适合目前两天原型的范围，本轮将它们替换为轻量目标，保留旧文件供对照。此处“两天”是制作约束，不是已验证的交付或性能承诺。

## 共同要求

三版采用人物背后的低第三人称跟随视角，沿用上一轮第三版深灰界面和琥珀色广播提示。场景只显示闸机大厅，用柱子、隔墙和折线路口表达复杂路线，站台在不透明墙后或下一段通道内，画面中不出现列车、轨道和站台。空间复杂来自动线和遮挡，装饰保持少量。

界面保留观战状态、广播、参赛者、选中角色体力、当前动作和近期事件。不放直接操纵角色的按钮，也不展示创造力技巧清单。临时名称和示例数字不构成规则变更。

## 方案一：积木通勤

图片：01-block-follow-v2.png。

保留第一轮积木方向，改为成人比例的方块身体、方块头与长肢体，取消可爱表情和玩具式俯视。暖灰、米色和少量橙色构成站厅，深色界面独立于场景。靠队伍分布、改道与姿态形成趣味。

实现以 Three.js 基础盒体、共享纯色材质为主，简单摆臂摆腿即可表达走跑；采用一个主光和环境光，减少实时阴影对象。场景用矩形墙、柱和重复闸机拼搭。图片地板和阴影仍是生成图的视觉示意，实现时继续简化。三版中该方案对现成角色资产依赖最低，最适合当前时间限制。

## 方案二：低多边形城市站厅

图片：02-lowpoly-station-v2.png。用户参考图保存在 user-style-reference.png，仅作风格参考。

从用户上传的便利店图提取棱面建筑、有限贴图、绿色导视和深色阴影，转换成室内闸机大厅，不复制商店、雨景、电线或俯视镜头。角色采用无精细五官的棱面人体与普通夹克，避免卡通大头和复杂服装。

技术仍可使用 Three.js。建筑用基础体块配少量平面导视贴图，环境低纹理、低反射。若有可直接使用且授权合适的低多边形人物与走跑动画，便可接近该方向；若需要从零建模、绑骨、制作动画，两天风险明显上升。图中的阴影和材质过渡可在真实实现时降低，不要求逐像素复现。

## 方案三：几何秩序

图片：03-geometric-transit-v2.png。

搜索参考选择 SUPERHOT 的几何人体、低纹理环境和少量高对比色；只借鉴简化方式，不采用枪械、战斗机制、时间机制或原作素材。官方视觉资料见 [SUPERHOT 品牌资料](https://superhotgame.com/documents/SUPERHOT-Brand-Guidelines.pdf)。本轮转换为冷灰站厅、深色闸机、蓝色选手与少量琥珀色导视，并保持第三人称。

实现采用低面数棱面人物、纯色材质和明确的平面阴影。导视靠简单几何和文字贴图，不做真实金属玻璃、复杂贴花和电影后期。人物仍需要走跑姿态；极简画风不能免去动画工作。该方向比第二版省去许多表面装饰，但轮廓、比例和配色需要调好。

## 两天内的实现边界

候选前端为 Vite + TypeScript + Three.js，文字界面用普通 HTML/CSS；若开发者已有 React 结构可继续使用，避免为这轮原型额外引入复杂框架。三种风格共用相机、布局与场景逻辑，主要差异在人物造型、颜色、贴图和着色。

先制作一个可玩的闸机区：左右队列、柱后绕行、折线出口和广播。地铁站其余区域可以后续扩展，不能把“镜头只看闸机”误解为正式世界里闸机直接连接列车。是否将两天试玩终点暂设在通过闸机或离开大厅，需要另行确定，不能悄悄改变正式登车目标。

固定地形用简单碰撞体、路点和队列占位；只有实际加入跳跃或击倒等需求时再接物理系统。人群以少量简单角色复用模型和材质，先实现走、跑、等待。灯管可用发亮颜色面模拟，不必每根灯管都生成实时光源。取消实时反射、体积雾、动态全局光照、精细面部、衣物模拟和大量背景物件。

以上仅约束视觉与原型范围。模型决策、权限过滤、紧急事件、创造力裁定和赛后报告仍是独立开发工作，两天完成视觉不代表已经完成整个 Agent 竞技系统。当前没有帧率、模型延迟或跨设备测试结果。

## 视觉检查与注意事项

生成图的文案、角色位置和动作气泡属于示意，实际网页要让气泡准确绑定所选角色。画面人物数量可以在原型中减少。风格差异应通过造型与材质体现，不通过增加昂贵特效体现。

## 几个术语可以这样理解

低多边形是用较少的三角面表示物体，棱面让这些表面转折保持可见。第三人称跟随指镜头从角色背后跟着移动。纯色材质用固定颜色表现物体，贴图则把图片附在模型表面。Three.js 是网页三维图形库，Vite 是开发与打包工具，TypeScript 是带类型检查的 JavaScript；HTML/CSS 用于界面文字与排版。
