## 比例与表面规则

- 列车保持原始1:1米制车体，头车约23米长、3.09米宽；车厢中心间距23.4米。48/54/66米站台每侧2节，72/78米每侧3节；两端头车朝外，长编组中间为拖车。不会把模型非均匀拉伸填满平台。
- 车轮基准位于站台下1.1米，门槛/乘客地板与站台等高；轨距展示与轮对位置一致，车体到站台边保留约0.16米间隙。车门保持关闭；本轮不新增上车/发车规则。
- 入站段沿现有6米水平距离下降4米，24级；站厅连接段沿真实12米端点下降6米，36级。楼梯具有闭合薄底板、石材踏面、双道防滑嵌条和护栏；扶梯具有槽面、梳齿落脚板、金属裙板、玻璃侧板及封闭回转橡胶扶手。
- 楼板开口顶层护栏沿连接方向布置，侧向布局不把入口封住；视觉设施不新增模拟碰撞。
- UV 在几何尺寸和变换后按米投射；金属0.6米、盲道0.3米、槽面0.24米一块，正式石材/墙面按3米材质模数。长轨道或楼梯不拉长单张纹理。
- PBR 区分涂装、石材、金属、玻璃和橡胶；法线/粗糙度承担微细节，不用数以万计的凸点/细槽独立网格。
- 座椅使用支脚、条板、靠背、扶手；自助售水组合有货架瓶身、玻璃/屏幕、取货口和充电立柱；安检台有托盘叠放边缘；设备房有门缝、把手、通风百叶和消防箱。

## 生命周期与降级

生成器静态世界、客流/事件随机流与游戏规则不变。正式素材失败时保留相同地图、本地新模型与原创备用 PBR 贴图；WebGL不可用时沿用二维路径。

共享站厅贴图归加载器；生成场景只释放自身纹理、材质和合并几何，列车临时建模几何合批后释放。按楼层切换可见性，入口顶盖/楼板开口/回放继续使用已有地图。模型细节不向模型提示词泄漏隐藏事实。

## 独立资产展厅与样板间

启动开发服务后打开 `/showroom.html`（默认 `http://localhost:5173/showroom.html`）。生产构建也包含同名页面，直接以HTTP服务托管dist即可访问；不依赖运行模型服务。

- **组合样板间**：固定云桥站，六个镜头查看双层剖视、站厅、入口、连接、站台与生活设施；可切换标识和站厅顶板，点选设备后单独查看。
- **单件资产**：56件模型，包含原站厅/栏杆模块、本轮列车、楼扶梯、通道、8类细节与9项休息室及旧版控制室展品；可分类搜索、比较变体、演示门扇与设备状态。
- **材质试样**：15种表面，以米制平面和曲面观察铺设、颗粒与光泽，并查看凹凸/粗糙度贴图。
- 拖动旋转、滚轮缩放、右键平移；可复位、环绕、全屏与保存PNG。按系统减少动态效果设置停用自动环绕；窄屏目录与信息面板重排。

例：`/showroom.html?mode=asset&asset=metro-head`、`/showroom.html?view=platform`、`/showroom.html?mode=material&surface=steel`。链接保留当前展品/空间，方便直接打开。

入口为 [showroom.html](../../showroom.html)，页面与场景代码位于 `src/showroom/`。游戏和样板间共用 `generatedStationPlacements`；正式平台仅在展厅显式启用前侧墙剖视。原样板工坊保持原位置，新页面不运行角色Agent或旅程计时。

范围和验收见[SHOWROOM-001任务](../../docs/tasks/SHOWROOM-001.md)及[验证](../../docs/validation/SHOWROOM-001.md)。

## 休息室资产与连续入口

[CONTROLROOM-004](../../docs/tasks/CONTROLROOM-004.md)沿用约8×6米建筑包络、双扇滑动门及侧通道，组合改为暖白/灰绿墙面、大块地面、圆角双人座椅、低边几/中空杯子、壁灯及03品牌立体字。角色站位、家具、镜头及入场路径共用休息室锚点，启动前检查实际家具占地与1.5米通道。

03字标的统一矢量主稿、SVG派生和品牌色见[品牌说明](../brand/README.md)；墙字用同一轮廓挤出约2厘米并小倒角，孔洞保留，不使用截图贴片或艺术字体替代。建筑/织物/涂装为本任务原创米制几何与哑光材质，不下载外部资产。主角与车站正式贴图沿用原资源。

展厅组合`control-suite`使用开顶剖视，游戏使用完整顶板。新增`control-seat`、`control-table`、`control-brand`，旧`control-console`、`control-wardrobe`独立链接保留并标注已从现行组合撤下；门扇仍支持开合滑块。页面品牌及favicon复用SVG主稿。

创建世界的地图只在独立UI预览，室内没有沙盘、电脑或控制台。固定休息室仍对接A口；模拟、地图摘要、乘客来源与计分规则不变。各资产释放自己的几何和材质，借用站厅加载器的资源保持原有所有权。
