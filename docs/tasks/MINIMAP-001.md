## 视图契约与完成条件

- 通用 Atlas 的楼层 ID 为字符串，含名称/高度/边界/几何/设施及显式连接器；当前 WorldDefinition 经只读适配进入 Atlas，未来生成器可提供更多楼层，无需重写绘制/选择/路线分层。
- 底图按世界对象缓存，动态层仅使用角色位置、实际 Activity 和现行可见性判定；不把世界真值中的隐藏人物/队列/未来事件传给小地图。
- 当前路线默认打开，显示偏好本机保存；局部小地图跟随角色，方向固定；展开支持平移缩放/楼层选择/回到角色，M/Escape 与触控/按钮可用。展开不改变既有暂停状态或计时。
- 跨层连接显示实际端点/进度，到达后换层；多层重合坐标不可串线；静态预览共享底图。旧报告回放只显示记录轨迹，不推测当时未记录的未来路线或动态人物。
- 入场演出隐藏，正式 watch 才显示；右侧 HUD 与播报避让，窄屏可折叠；2D 降级可用，不新增 WebGL 上下文。
