# WORLDGEN-V3-002：站长随机化与楼扶梯比例修正

状态：2026-11-01 本地实现与本轮验证通过，待用户视觉确认；本聊天Codex为单一负责人及集成人。

## 基线与授权

- 干净基线：codex/worldgen-v3，`92ce95e7272ad022854bd52e0f9fd23f40c223cb`。继续同一空闲工作区串行修正，不修改其他来源工作区。
- 用户指出M1在72米短站中两组相向连接下口只有4米间距，空间关系不合理；本轮明确追加“把车站长度也做为一种随机因素”。此授权扩展此前66–78米紧凑档位，不代表三类站厅布局或其余M2/M3已经获视觉验收。
- 本轮采用78/102/126/150米四档起点，对应3/4/5/6节现有米制车厢；不缩放车厢。站长、列车编组、连接组间距、柱网/顶面和设施位置共同派生。

## 允许范围与接口

- 允许src/shared/world与generatedTrain、src/sim的建筑/版本恢复/摆放/比例、队伍绕行和可达预算、src/ui与showroom的相关消费者、对应tests/scripts及本任务/验证/说明/中央记录/导航。
- 排除依赖/锁文件、角色素材、其他工作区、地面街景/换乘/新玩法、时间/服务/队列平衡参数；不推送、合并、部署或调用付费模型。
- A端闸机线退至21米，闸后分配宽度为6米；候梯队列直排3米后向远离楼梯一侧折返，全部14个位次按行李半径检查，设施禁放区同步。扶梯接近点保留0.2米走路容差后的上梯余量；绕人偏离静态路径后重新寻路。
- 保留两组楼梯+扶梯，但改为同向纵向错开；最短档两组下口间隔至少24米，下口组合平台留白单独占地。设施、座椅、柱体和另一组下口不能侵入该区。
- 新定义增加可选显式列车节数、到达平台区域、候梯队列转折点及入口预算；新长站从同一静态定义派生渲染、屏蔽门/登车、镜头、二维和小地图。
- 旧V3融合样板（种子1摘要8e3cc409）使用冻结工厂恢复；旧两种V2和V1继续按摘要匹配，不能以新随机长度重建旧记录。
- 长度抽样使用独立结构随机流；装饰修改不能影响长度、连接位置或运营抽样。
