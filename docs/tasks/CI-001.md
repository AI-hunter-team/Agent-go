## 实施与完成条件

- 先将 DOC-001 文档独立提交，再提交 CI 工作流及相应开发说明，方便审阅与回退。
- CI 在 `main` 的 push、面向 `main` 的 pull request 和手动触发时运行；Node.js 24，Ubuntu/Windows 两种环境执行 `npm ci`、`npm run typecheck`、`npm test`、`npm run build`，使用只读仓库权限与 npm 下载缓存。

## 风险、回退与交接

新 CI 可能发现环境或现有测试问题；先定位，超出允许范围则记录，不悄悄改业务或跳过失败检查。需要回退时，在已授权的集成流程中按目标提交执行 revert，保留后续他人工作；不重写远端历史或执行破坏性清理。PR、受测 commit、命令结果及实际集成状态由验证报告和中央记录承载。
