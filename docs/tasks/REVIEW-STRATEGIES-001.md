- 授权：用户明确要求移除复盘底部按钮，将下一轮提示词策略放在“下一局怎么走”首位，勾选后启用“使用选中策略再来一局”，进入开局设置并填充所选策略。

- 决定：策略默认展开并保持未选；选中后一次点击调用已有指导草稿 API，按所选策略整理有效的 300 字以内指导，成功后直接进入指导设置页。生成中防止重复提交；失败或选项变化时不跳转，不采用过期结果。沿用本局用户配置优先、服务端兜底的 API 路径。

- 排除：模拟规则、计分、供应商协议和实际密钥；不调用付费模型，不提交、推送、远端合入或公网部署。
