明白，上一条只展开了警戒机制。下面沿用上一版的整体结构，把你补充的颜色、圆环、判负规则和肢体行为融合进去，形成完整方案。以下仍是设计提案。

## 1．把几个阶段连成相互影响的一条路线

| 阶段 | 角色可以做什么 | 对后续产生的影响 |
|---|---|---|
| 取得车票 | 买票、逃票、索要、交换、用话术说服、威胁或抢夺 | 改变耗时、车票归属，以及相关乘客的态度和警戒状态 |
| 安检 | 有包或无包通过；携带道具；制造动静吸引注意；与安保发生肢体冲突 | 无包更快，有包可以携带更多道具；异常行为可能引起调查、阻拦 |
| 闸机 | 持票通行、翻越闸机或栏杆、利用注意力转移寻找机会 | 翻越被 NPC 目击会引发红色反应，被保安确认发现则立即判负 |
| 楼梯与扶梯 | 走楼梯、乘扶梯、遇到拥堵时中途翻出、沿扶手滑下 | 路线耗时不同，也可能产生碰撞、惊扰和目击事件 |
| 全程排队 | 正常排队、请求让位、给好处、强行插队 | 乘客可能同意、拒绝、争执或驱赶；NPC 自己也可能插队 |

这些阶段共享同一个世界状态。例如，角色背包去取道具，会增加取物和安检时间，但道具可能帮助后面转移注意；抢票省下买票时间，却可能留下一个持续警戒的乘客。

**不买票本身不会被查。** 保安不能凭空知道角色是否付费，只能根据实际感知到的抢夺、翻栏杆等行为作出反应。

## 2．每名乘客都有形象、性格、处境和记忆

开局生成 NPC 时，包含：

- 外在形象：外貌、衣着、携带物品、动作与说话风格。
- 稳定性格：胆量、虚荣心、脾气、公平意识、是否愿意管闲事。
- 当前处境：赶时间、疲惫、有同行者、携带行李等。
- 局内记忆：角色对他做过什么，他目击过什么，目前在关注谁。

这些因素共同决定反应。胆小的人可能被威胁后交出票，也可能逃跑求助；虚荣的人更容易接受恭维，但不一定让出票；重视公平的人可能驱赶插队者，也可能主动阻拦抢夺。

**颜色表示受到影响的程度，性格决定具体怎么反应。** 同为红色，胆小乘客可能逃离，强势乘客可能挺身而出，另一些人会报告保安。

角色不能直接读取完整性格，需要通过外表、言语和行为判断对象。

## 3．允许自由描述行动，由环境裁定实际结果

基础操作仍然是移动、观察、交谈、拿取、使用、交付、等待；角色也可以用一句自然语言组合这些操作。

例如：

> “我拿着手里的道具，走到那位乘客面前，强硬地要求他交出票。”

Boss 需要识别：对谁、用什么、做什么、希望达到什么目的，再检查位置、道具、目标状态和行动耗时。

肢体行为纳入允许范围，包括抢夺、推搡、击晕等，但提出行动不等于指定成功。一次动作可能被拒绝、反抗、中断，也可能成功后引起其他人的反应。

物品必须真实存在并有归属：

- 道具需要去指定位置取得，不能通过描述凭空出现。
- 背包决定携带空间，同时影响安检耗时。
- 车票被交付或抢走后，归属实际转移。
- 使用道具产生的声音、位移或人物状态变化，都进入环境结算。

因此，道具不必只有一种固定用途。同一物品可以被交给别人、丢下制造声音，或用于肢体行为；环境分别判断其效果。

## 4．将白黄红与圆环嵌入“感知—判断—行动”

完整反应链为：

事件发生 → 人物看到或听到 → 判断与自己有什么关系 → 亮起状态点并采取行动 → 持续观察导致升级。

| 状态 | 即时表现 | 圆环填满后的变化 | 消失条件 |
|---|---|---|---|
| NPC 白色 | 对奇怪但暂时无害的行为看一眼、议论、保持距离 | 升为黄色 | 最容易消失，脱离观察范围短时间即可解除 |
| NPC 黄色 | 自己受到影响，表现为不满、争执、驱赶 | 升为红色 | 角色连续离开其视野较长时间后解除 |
| NPC 红色 | 感到危险或明确目击严重违规，躲避、求助、阻拦或报告 | 不再升级 | 本局不消失 |
| 保安黄色 | 对可疑行为或动静产生警觉，观察、靠近、调查 | 升为红色 | 连续脱离视野一段时间，且没有新的确认事实后解除 |
| 保安红色 | 确认违规，或黄色观察进度填满 | 立即判负 | 不可解除 |

点亮后立即产生对应反应，圆环从零开始表示向下一状态发展的进度。升级后，圆环重新从零开始；红色不再倒计时。

圆环遵循几个统一规则：

- 只有被具体事件触发，才开始关注；正常走路、排队不会自动亮白点。
- 持续观察到相关角色时，圆环增长。
- 离开观察范围或被遮挡后，停止增长。
- 短暂躲开再回来，保留进度；连续隐藏足够时间，白色或黄色才消失。
- 严重行为可以直接进入更高状态。翻栏杆被 NPC 明确目击，NPC 直接红色；被保安确认发现，保安直接红色并判负。

同时保留“被惊动”和“认出行为者”的区别。听见碰撞声的人可以看向现场，但不能自动知道是角色造成的；只有看到了相关行为，或得到足够明确的信息，才能把关注指向角色。

NPC 红色不会直接判负，也不意味着永远追赶，但会保留记忆和态度。报告保安需要喊话、接近或其他实际传递过程，不能让全站瞬间共享信息。

## 5．Boss 是中立裁判，人物通过自己的感知行动

| 部分 | 职责 |
|---|---|
| 角色 Agent | 根据观察和玩家指导选择行动 |
| NPC 与保安 | 根据性格、处境、感知和记忆回应 |
| 环境 Boss Agent | 理解非常规行动，裁定合理结果，协调相关人物和事件 |
| 模拟器 | 执行移动、耗时、物品转移、视野、圆环和判负规则 |

Boss 可以掌握全局事实，但不能让人物使用自己不知道的信息，也不能因为角色取巧临时增加惩罚。

普通移动、排队、警戒计时由程序持续运行；关键对话、非常规行为和复杂反应再调用模型判断。模型思考时可以暂停世界，动作执行期间世界继续运行，人物可以走开、转头或打断行动。

击晕保安成功后，会暂时停止其观察和行动；但其他目击者仍可能反应。已经进入红色的保安不能再通过击晕“撤销判负”。

## 6．让局部行为通过事件链改变整个环境

例如，角色在安检附近丢下物品：

1. 物品落地产生声音，附近人物根据距离和遮挡感知动静。
2. 乘客转头、停步或绕行，安保可能前去查看。
3. 如果有人看到角色丢东西，就可能对角色亮白点；角色持续留在视野内，圆环增长。
4. 如果物品撞到乘客，对方受到直接影响，可以进入黄色并争执、驱赶。
5. 如果随后发生抢夺或肢体冲突，受害者及目击者可能直接进入红色。
6. 红色 NPC 逃离、阻拦或报告；保安获得信息后调查，确认违规则红色判负。

断电、设施损坏等也沿用这条链：先改变设备与照明，再引发乘客和保安的反应。爆炸等更大事件可以放在后续扩展，增援也需要实际到场过程。

实现顺序建议仍是先完成一个小而完整的闭环：

取道具／交涉 → 索要或抢票 → 状态点与圆环 → 目击和报告 → 保安调查与判负。

随后把翻闸、安检和楼梯扶梯接入同一机制。现有 120 秒限时需要结合新动作耗时重新试玩评估，确保取道具、交涉和躲避都有实际使用空间。
