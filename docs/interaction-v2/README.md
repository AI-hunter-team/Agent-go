# 交互 2.0（角色、NPC、警戒与自由行动）

状态：**规划已确认，待实施**（2026-10-31）。本专题是根据用户提供的[角色设计提案](source-角色设计.md)整理的实施规划，尚无代码实现。用户于 2026-10-31 在 Claude Code 会话中明确接受 D1–D8 的推荐方案（见[已确认决定](#已确认决定)）；交互 2.0 的规则随各任务实现并验证后，再替代 [Demo 方案 1.1](../Demo方案1.1.md) 中对应部分。圆环秒数、成功率、耗时等数值仍是可调起始值，不属于已确认内容。规划任务记录见 [IV2-00](../tasks/IV2-00.md)。

## 一句话

在现有“模拟器裁定、模型只提意图、思考即子弹时间”的架构上，增加**物品归属、NPC 人设与记忆、事件感知、白黄红警戒圆环、Boss 自由行动解释**五个子系统，让取票、安检、闸机、楼梯扶梯和排队共享同一个世界状态和同一条“事件 → 感知 → 警戒 → 反应”链。技术栈不变，不新增运行时依赖。

## 范围

**包含**：车票等物品实体化；背包与安检耗时；NPC 外观 / 性格 / 处境 / 记忆；视觉与听觉感知、归因；NPC 白黄红与保安黄红警戒圆环；NPC 反应（议论、争执、驱赶、逃离、阻拦、报告）；保安调查、注视、击晕；自然语言自由行动经 Boss 解释为原语计划并由模拟器执行；通用 NPC 对话（索要、交换、说服、威胁、贿赂、让位）；扶梯与楼梯；NPC 插队；断电与设施损坏事件链；对应展示、报告与复盘。

**不包含**：爆炸与增援、多人对战、跨局记忆、正式角色美术资产、部署。

## 现有架构里可直接复用的部分

| 已有能力 | 位置 | 在 2.0 中的角色 |
|---|---|---|
| 固定步长确定性模拟、单一事实来源 | `src/sim/engine.ts`、`world.ts` | 新子系统按固定顺序挂进 `Engine.step` |
| 子弹时间与串行模型调用 | `src/agent/runner.ts` | 扩展到 Boss 与 NPC 对话 |
| 视锥、视线遮挡 | `src/sim/geometry.ts` | 感知系统直接复用 |
| 结构化输出、双供应商、调试追踪、安全包装 | `server/structured.ts`、`claude.ts`、`openai.ts`、`debug.ts`、`security.ts` | Boss / NPC 对话沿用同一模式 |
| NPC 插队协商（性格 + 三轮 + 只认模型明确同意） | `src/sim/negotiation.ts`、`runner.ts` | 泛化为通用 `talk` |
| 3D 展示快照与插值 | `src/ui/presentation.ts`、`scene/*` | 增加状态点、圆环、物品、台词 |

需要替换的：`src/sim/creative.ts`（两种硬编码机制）→ 行动执行器；保安“看见违规即判负”→ 警戒状态机；`hasTicket` 布尔 → 车票物品。

## 已确认决定

用户于 2026-10-31 在 Claude Code 会话中明确接受 D1–D8 的推荐方案，以下各项为本专题的确认结论。表中未列出的数值仍是试玩起始值。

| 编号 | 问题 | 确认结论 | 影响任务 |
|---|---|---|---|
| D1 | 背包是赛前选择还是局内获得？能否中途丢包？ | 赛前在开局面板选择（默认带包）；局内可 `drop` 背包，丢下后背包内物品留在包里 | IV2-02、IV2-13 |
| D2 | 角色 Agent 能否看到 NPC / 保安的颜色与圆环？ | 不能看到数值；只看到可见表现（“盯着你”“朝保安跑去”）。观战 UI 显示颜色与圆环 | IV2-02、IV2-10、IV2-11 |
| D3 | 时限 | M4 前保持 120 秒；IV2-18 试玩后给出建议再定 | IV2-18 |
| D4 | 强行插队、威胁对保安的严重度 | 强插 = `affecting`（被插者黄，保安看到为黄）；威胁 = `danger`（受害者红，保安看到为黄，不直接判负） | IV2-05、IV2-16 |
| D5 | 肢体行为对象与表现 | 推搡、抢夺、击打、击晕可针对任何人；画面与文字保持非血腥（倒地、晕眩符号） | IV2-08、IV2-11 |
| D6 | 道具清单、起始物品 | design.md C2 的 7 种；角色起始口袋有零钱，无其他道具 | IV2-02 |
| D7 | 赛后是否公开 NPC 隐藏性格 | 公开，用于复盘 | IV2-19 |
| D8 | Boss / NPC 对话用哪个模型、预算多少 | 与角色使用同一模型配置；每局角色 80 / Boss 20 / NPC 30 次，用尽退化为离线 | IV2-09、IV2-10 |
