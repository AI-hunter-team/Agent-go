## 未完成的验收

1. **真实模型整局**：需要用户自己的可用凭据和额度，验证真实供应商支持所选模型及请求参数、1024 输出预算下工具调用的稳定性。
2. **指导差异**：同种子分别提交不同自然语言指导，检查是否产生可观察差异；当前离线 Agent 不读取指导。
3. **真实费用与延迟**：测试没有产生 API 账单，不能给出经过实测的价格或等待时间。
4. **最新 UI 浏览器复验**：恢复工具后验证暂停时结束、思考时结束、窄屏布局、JSON 下载、同种子重试。

## 交付边界

- 本地开发演示，不含账号、数据库、联网匹配、3D、历史局存储或逐帧回放。
- 评分只有过闸世界时间；失败无成绩。决策数、token 与违规记录是诊断信息，不加权评分。
- 单次角色决策请求的总输出硬上限为 1024，包含思考与工具调用。每个决策机会可重试一次，每次分别限额；辅助调用和拒答回退见技术方案第十四节。
- 模拟由浏览器可信客户端执行，不是防作弊的权威服务端。API 仅绑定本机；不要直接作为公网生产服务开放。
- 所有运行参数集中在 `src/sim/scenario.ts` 与 `layout.ts`，可后续调整。玩法参数是本轮实现初值，不代表已完成体验调优。
