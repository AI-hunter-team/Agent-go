## 交付边界

- 本地开发演示，不含账号、数据库、联网匹配、3D、历史局存储或逐帧回放。
- 评分只有过闸世界时间；失败无成绩。决策数、token 与违规记录是诊断信息，不加权评分。
- 单次思考预算为 1024；工具与说明不占用这个额度，总输出保护值另设为 4096。当前协议通过提示及 usage 检查执行预算，不具备经确认的供应商生成时数值思考硬上限。缺少明细的请求无法验证思考长度。
- 模拟由浏览器可信客户端执行，不是防作弊的权威服务端。API 仅绑定本机；不要直接作为公网生产服务开放。
- 所有运行参数集中在 `src/sim/scenario.ts` 与 `layout.ts`，可后续调整。玩法参数是本轮实现初值，不代表已完成体验调优。

### 更正预算后的最终结果

用户确认 **1024 只约束思考，不约束全部输出**。最终配置为 `DECISION_THINKING_TOKENS=1024`、`DECISION_MAX_TOKENS=4096`，动作和说明不占用思考额度。回归测试验证：总输出 1600、思考 1000 时允许动作；思考 1025 时拒绝执行。

| 检查 | 结果 |
|---|---|
| `npm test` | 15 个文件、127 项全部通过；本机 HTTP 测试需允许监听临时端口 |
| `npm run build` | 类型检查与构建通过 |
| `git diff --check` | 通过 |
| `npm run test:model -- --seeds=1` | 真实 Luna 整局成功，种子 1，52.7 秒，13 次决策 |

| 现实调用等待 | 累计 95.0 秒，中位单次约 7.33 秒；不计入游戏成绩 |

完整报告：[最终配置实测 JSON](model-tests/2026-10-30T11-08-17-997Z.json)。

接口的标准推理参数控制强度，未确认有可独立设置为 1024 的数值思考硬上限。当前采用预算提示、low 强度及响应后的 `reasoning_tokens` 校验；超限动作拒绝执行，但不能撤销供应商已产生的 token。缺少明细时不能证明该次思考符合预算，也不能用总输出上限代替思考上限。参考 [OpenAI 官方推理参数说明](https://developers.openai.com/api/docs/guides/reasoning)。
