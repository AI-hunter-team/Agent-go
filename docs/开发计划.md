## 里程碑

- **M1 模拟器可测**（#3–#13）：无 UI，测试覆盖全部规则。
- **M2 离线可玩**（#14–#15、#20–#22）：浏览器里离线 Agent 跑完一局并出报告。
- **M3 接入大模型**（#16–#19）：配置 API Key 后由模型决策，指导整理与创造性归类可用。

实际执行时 M3 的服务端提交排在 UI 之前（按上表顺序），保证 UI 一次接好两种 Agent。

## 完成标准

- `npm test` 全部通过；`npm run build` 成功。
- 离线 Agent 在默认种子下通关并产出报告。
- 配置 Key 后，大模型 Agent 能完成一局（手动冒烟）。
- 远端仓库链接提供后再推送；在此之前只在本地提交。
