# 决策调用记录

按顺序保留角色模型 API 实际返回的全部内容块，包括思考、普通文本与工具参数；保留每次调用的输入观察、开始结束时间、错误、Token 用量及执行结果。不能记录服务商未返回的内部推理，不生成补写的思考。

现有报告增加逐次调用记录，兼容旧报告；一次决策的失败和重试都保留。取消时的在途调用仍有记录，迟到响应只归档、不执行。报告总用量包含这些已返回调用，不重复累计重试。

后续用户追加：将现有通行规则清楚展示为买票、安检、过闸机、进入站台四个阶段，在闸机阶段显示排队与验票状态，地图标注闸机区；复用已有验票与通行耗时，不添加重复的闸机执行或改变计分。

决策卡片可展开查看逐次调用，结束报告提供全局调用记录并随 JSON 导出。保持原有思考预算、模型计费策略和游戏规则，不新增模型请求。记录保留在当前页面，用户可导出保存。
