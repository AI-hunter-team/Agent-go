## 函数职责

本轮修改到的函数已补中文注释；匿名的 React 事件回调沿用所在函数职责。

| 函数 | 做什么 |
|---|---|
| `SceneBoundary.getDerivedStateFromError` / `render` | 记录三维渲染失败，并切换到恢复界面 |
| `Brand` | 绘制现有品牌标记与名称 |
| `downloadMetrics` | 导出开发采样 JSON |
| `App` | 组合开局、场景、观战、报告与弹窗；仍从原会话读取世界状态 |
| `onAssetError` / `onSceneFailure` | 接收素材与场景错误并交给相应展示状态 |
| `change` | 跟随系统减少动态偏好；后续性能任务可以接替此职责 |
| `prepare` | 整理指导，成功后进入确认；过期请求不会覆盖当前状态 |
| `start` | 创建所选 Agent，按既有规则启动一局 |
| `edit` | 回到设置，按当前种子重置预览 |
| `retryScene` | 重建失败的三维场景，不重启对局 |
| `applyAsset` | 验证本地模型路径并触发加载 |
| `SetupPanel` | 展示模式、指导、种子与准备按钮 |
| `GuidanceCard` / `list` | 展示原始指导与非空的整理分组 |
| `Controls` | 保留二维兼容暂停、倍速、视野与结束操作 |
| `ModelConfigPanel` | 展示模型配置，关联现有接口与思考档位 |
| `invalidate` / `verify` | 丢弃未启用凭据和状态；验证接口并获取模型 |
| `enable` / `clear` | 启用所选模型/档位；清除页面配置，均保留原有业务语义 |
| `JourneyProgress` | 从真实角色状态计算五个流程节点 |
| `ReportSummary` / `exportJson` | 汇总终局数据，原样导出报告 |
| `EventTimeline` | 展示事件并切换角色感知过滤 |
| `TrajectoryReplay` / `tick` / `seek` | 管理回放状态，按帧推进时钟，暂停并跳到指定时间 |
| `TrajectoryReplayView` | 将历史地图与回放控制器接到同一只读回放帧 |
| `Icon` | 绘制箭头、回正、关闭和展开的统一 SVG 线条图标 |
| `Modal` / `Hint` | 提供带焦点管理的弹窗，以及悬停/聚焦提示 |

## 浏览器核对

- 应用内浏览器，按实际 CSS 视口检查 1440×900、1024×768、390×844、320×800。浏览器原本有缩放，使用尺寸模拟后读取 `innerWidth/innerHeight` 确认，不按截图像素猜测。
- 开局 → 确认 → 观战；暂停/继续、1/2/4 倍速、行程阶段与当前行动、显示设置打开/关闭：通过。
- 种子 1 离线在固定 120 秒规则下超时，失败原因与无成绩正确显示；这与既有 `heuristicAgent.test.ts` 的预期一致，不修改策略或规则。
- 失败报告的完整耗时、调用记录入口和轨迹回放打开通过；回放播放、下一决策、时间变化、弹窗内滚动与持续可见的关闭按钮通过。
- 模型配置使用伪服务验证连接、获取列表、选择高档思考并启用成功；301 字指导显示超限状态并禁用整理按钮，清空后恢复。
- 生产构建种子 5 离线整局成功：114.7 秒，14 次决策，无违规；五个节点、成绩、四项耗时均正确显示。320px 宽度页面 `scrollWidth === innerWidth`，完整行程记录弹窗的长文字、独立滚动和关闭按钮通过。
- 真实模型、实体设备、场景强制故障、NPC 沟通现场与浏览器下载未重新验收；相关展示沿用统一样式，既有软件测试通过不代替这些实测。不新增自动化浏览器测试。
