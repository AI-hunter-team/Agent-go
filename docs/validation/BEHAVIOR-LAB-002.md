## 已实现的行为

- 新增 PhysicalAction/physical_action 工具：action 为 push/snatch/strike，npcId 为对象；击打区分 hurt/knockout，抢夺指定实际物品种类，手持工具传 itemId。可选 speech 独立携带台词、对话目标与交换物品。传输和 Engine 共用字段校验，转换为现有步骤逐项执行；未改变模拟器裁定成败的职责。
- 对话结束后继续独立肢体步骤。先行对话因正式三轮上限、对象无法交谈等前置条件不能开始时，记录 speech_skipped，再校验独立动作，不把话术限制当成禁止动手。对话调用故障、目标失能/不可见、反抗、物品缺失或判负仍会中止相应尝试。
- 角色默认提示和环境解释说明区分台词与实际行动。测试页对明确、无条件的动作被纯 talk 遗漏进行显式补回并显示校验记录；引用、否定、条件句不自动补成无条件攻击，对象不一致或武器缺失不盲目补回。关键词解释支持逗号分隔的先威胁再殴打、同一对象的省略指代及真实击打物品，不把说话内容里的打人当作动作。
- 移除 chat/persuade 的一概禁止物品交付；NPC 明确同意后转移真实未使用物品，保持容量、所有权和原子性检查。yield 只让位、索票应交真票、交易应有实际物品的规则保留。
- 正式默认性格生成改为七组鲜明组合加小幅扰动，NPC 对话提示解释五项数值的含义，并明确可以同意或拒绝，不统一拒绝。离线回复依据性格与处境展示不同倾向，不能替代真实模型表现。
- 测试页默认每条新输入恢复整个初始场景，清空 NPC 对话次数/记忆/警戒；保留所选性格参数与历次记录。关闭选项后才连续测试。后果观察按钮仍推进当前世界，不自动重置。
- 可为所有乘客或单名乘客选择七组模板、五项性格以及赶时间/疲惫参数；单名设置优先，范围0–1。参数进入真实 NPC 对话请求；角色仍不能读取隐藏性格。
