## 浏览器验收

使用既有 `tests/fixtures/journeyServer.ts` 在 8899 启动隔离无费用服务，未读取真实模型凭据。应用内浏览器执行实际 UI 操作。

- 每局记录默认展开，头顶仅图标；暂停后收起记录，头顶立即显示“先到并排售票机前比较可见队列”；再次展开后头顶文本为空且模式为 icons。
- 初验发现暂停时模式切换不触发按需绘制；`Contents` 在消息模式/思考状态变化时显式 invalidate 后复验通过。

- 点击“再来一局”进入现有准备流程，新局记录恢复默认展开，旧复盘不再挂载。
- 离线 seed 1、300 秒时限实际到达站台，130.8 秒成功；成功后也默认仅底部入口，点开复盘才显示成绩与回放。真实模型整局未测试。
- 390×844 窄屏：无水平溢出；复盘底部 y=744，两个底部按钮 y=776–824，按钮并排且不与报告重叠；观战时折叠按钮位于左上，计时位于右上，头顶正文可读。临时 viewport 已恢复。
- 最终构建再次加载后复验暂停折叠正文及手动结束的两个入口，并保存本地效果图；测试标签与隔离服务在交付前关闭。
