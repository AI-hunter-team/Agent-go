## 浏览器实测

使用伪模型指导 `稳妥通关 FAIL-DECISION` 复现连续三次决策失败：

1. 自动生成失败复盘，显示主因、当时已知/赛后发现、策略与代价，两条建议均默认未选。
2. 只选择「谨慎换队」，生成原指导与该建议合并的草稿；未选建议未加入。
3. 编辑为 301 个 Unicode emoji，显示 301/300 与错误，采用按钮禁用；恢复有效文字后可采用。
4. 点击采用后回到设置，保留新指导，等待玩家整理与确认，没有自动开始下一局。
5. 重跑失败局，在结束页进入模型配置，终局、复盘、导出按钮保持；返回复盘后报告仍在。
6. 导出 JSON 成功并读取核对：`status=failed`、3 个全局快照、2 条策略、1 次复盘调用记录、空采纳列表。
7. 检视复盘弹窗及草稿截图，原指导、可编辑草稿、字数与采用动作可见。
