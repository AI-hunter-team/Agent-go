## 易拉罐与真实状态

- 用户追加“不要报纸，改易拉罐”：新局物品种类替换为 can（空易拉罐），便利架库存、模型枚举、自然语言识别、人物物品协议和前端标签一致更新。新实现中不再生成报纸。历史 debug 和已导出的旧对局不改写，不提供旧运行中途迁移；需要开新局。
- 易拉罐占1个持物单位，普通落地声音半径6米、投掷落地9米；遮挡按既有听觉规则折减。不能凭空出现罐子或默认已拿到；正式角色仍须自行寻找并取得。
- 抛掷动作准备1秒，离手后物品进入真实 flight 位置，包含 from/to/startedAt/landsAt/actorId/causeId。飞行0.5秒期间不在持物中、不能拾取；由模拟时钟推进位置。
- 释放事件 item_thrown 在起点记录轨迹，声音0；实际到达终点才移为 ground、记录 land 转移并产生带落点和声音的 item_dropped。重复推进不重复落地。落地后可观察、走近拾取；不会出现手上与地上两个罐子。
- 指向人物时，落点在离手后固定；落地检查人物是否仍在0.6米内，移开的人不会被“追踪弹”命中。
- 前端 SceneItems 从同一物品快照采样轨迹，增加带罐口/金属罐体的圆柱模型。保安 Character 的位置、朝向继续读取世界 Guard 状态；没有播放动画来反写保安视线。
- 架构边界：本项目世界模拟器运行于浏览器，服务端代理负责模型调用/解释；本轮没有把整个世界迁移到服务器。这里的权威坐标是模拟层真实状态，区别于渲染层装饰坐标，不宣称存在新增服务器物理进程。

## 保安反应及边界

- 落地事件进入原感知系统；未知行为者的声音引发向实际落点的调查、行走和转向。已有有向追踪/更高优先级报告不会被普通声音强制清除，听觉不凭空识别人。
- 修复实际释放当帧的目击归因：角色和抛出都看得见时，不因动作刚结束而将可见角色错误算成未知动静；落地听觉仍不自动识别投掷者。普通抛物按原 odd 级别处理，没有改成统一判负或无条件吸引。
- 捕获坐标复现：角色(25.3,10)，S2(28.5,12.5)朝西，起初视线覆盖角色。投掷真实易拉罐到(30,10)，落地后S2向该点移动，当前视线不再覆盖角色；观察字段也反映“前往动静处查看”。这是一次模拟机会，不保证3秒翻越过程始终安全，也不代替角色重新观察。
