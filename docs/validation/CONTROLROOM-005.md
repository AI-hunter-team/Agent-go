# CONTROLROOM-005：桌面首页菜单底色验证

## 范围与基线

在 `codex/worldgen-lounge-minimap-pr` 的 `55dab41ef48598f0032ea28b170881e9b2d247ff` 上，按用户要求让桌面首页次级菜单使用手机已有的半透明暖白底色；任务范围见[简报](../tasks/CONTROLROOM-005.md)。

## 检查结果

- 原因：桌面 `.welcome>button` 使用透明背景，600 像素及以下媒体查询覆盖为 `#f6f3eae0`。现统一放在通用规则，主按钮保留黄色。
- 本地生产构建和浏览器伪服务：1440×900、768×900 和 390×844 分别检查首页，次级按钮计算背景均为 `rgba(246, 243, 234, 0.88)`，主按钮均为 `rgb(255, 198, 0)`；“创建世界”“我的世界”“角色外观”打开及返回正常，未观察到页面脚本异常。
- `npm run typecheck`、`npm test`（102文件、887项通过，使用两个工作进程）、`npm run build` 通过。构建仍有既有大块提示。
- 390 像素为浏览器模拟尺寸，不代表移动真机验收；本项不改游戏规则，也未运行真实模型。

最终提交、远端 CI 和是否合入以 [PR #68](https://github.com/AI-hunter-team/Agent-go/pull/68) 为准。
