## 变更与回归

- 每局独立设置时限和初始开放队列额外人数。Engine 与服务端会话复制冻结参数，预览、同条件重试、观察、两种供应商提示词、计时、报告和两种 JSON 导出使用同一组值。旧调用默认 180 秒 / +0，旧报告兼容默认展示。
- 故障根因是状态更新只解散队列，未取消 serving，且服务结算先于设施状态检查。现在 broken/closed 立即取消未完成办理，阻止售票、安检、普通过闸完成；同一 tick 故障优先，恢复开放后重新办理，已完成票和安检不撤销。玩家和 NPC 都适用。

- 楼梯测试原先在初始故障 G3 上人工注入办理成功；改为先显式开放 G3，以继续验证正常过闸到楼梯的流程。故障行为由新回归独立检查。
