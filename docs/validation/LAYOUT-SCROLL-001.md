## 原因与修复

1. `preparation` 依赖 `translateY(-50%)` 居中，但 `panel-in` 动画最终值覆盖了 transform。1280×720 时面板停在 y≈360，导致下半部分超出视口；改为透明度入场，保留真实居中定位。
2. 装饰 `::after` 的负 inset 和横向运动参与溢出计算，光带透明后仍撑开滚动范围。移除该装饰，未用隐藏滚动条掩盖问题。
3. 指导页 `100dvh - 140px`、手机 `58dvh` 的限制过严；改为保留必要边距后利用可用高度。中间宽度缩略图随宽度调整，横向矮屏采用紧凑选角布局。
4. 小屏控制栏换成两行后，单独绝对定位的信息按钮盖住暂停；合并为共同底部网格，历史报告入口也进入同一布局。背景空白仍可操作场景，按钮仍可点击。
5. 气泡只互相避让，未考虑计时器等 HUD。沿用原算法，增加实际 HUD 矩形的避让，所有 DOM 读取仍集中在样式写入之前；不新增每帧 React 状态或事件订阅。
6. 复盘摘要收紧留白，避免可容纳时出现滚动；移除手机决策卡片的滚动吸附。长记录、小屏长表单仍允许实际需要的滚动。
