## 性能对照

在同一台机器的 NVIDIA RTX 5090 Laptop GPU、Edge 156、1440×1000、DPR 1、标准画质、60 FPS目标、种子1及入场后等待8秒条件下采样60.01秒：P95帧间隔从 CONTROLROOM-004 基线的17.7 ms变为17.5 ms，约改善1.1%，未超过恶化20%的门槛；平均60.46 FPS，3628帧。采样时绘制调用667→656，三角形820,186→1,226,992，几何体418→420、纹理97→96；三角形增加约49.6%，是精细车厢合入后的材料风险，本机结果不代表其他设备性能。
