## 浏览器检查

使用本地生产构建和无费用浏览器伪模型服务；没有调用真实付费模型。桌面检查休息室、数字种子2、3D/B1/B2地图预览和长镜头，入口交接前后角色及摄像机的 UUID 一致，计时从入站楼梯开始；种子1以85.2秒实际进入车厢，检查了三维车厢胜利画面。390×844 模拟窗口检查独立角色外观、刷新恢复默认外观、继承到新世界和设置入口。

同一窄窗口使用二维画面，实际创建种子2、暂停并打开整站地图、4倍速完成离线对局（134.4秒实际登车），打开复盘；最终主线复盘保留“下一局怎么走／轨迹回放／完整行程记录”三个页面，终局“同世界重试”保留种子2，再来一局生成并保存新种子。正常流程未观察到页面脚本异常。早期桌面长镜头与本次窄屏最终完整局分别执行，不将截图或历史版本验证冒充当前全部视角验收。

预览的 WebGL 上下文被单独阻断时，自动切到同一地图的B1平面图，休息室摄像机保持同一实例，仍能确认创建。对文字种子“石桥”，无费用伪模型的准备、建会话和首次决策请求均返回200，准备和会话携带相同 `metro-v1` 摘要；这不代表真实模型验收。

## 性能对照

在同一台机器的 NVIDIA RTX 5090 Laptop GPU、Edge 156、1440×1000、DPR 1、标准画质、60 FPS目标、种子1及入场后等待8秒条件下采样60.01秒：P95帧间隔从 CONTROLROOM-004 基线的17.7 ms变为17.4 ms，约改善1.7%，未超过恶化20%的门槛；平均60.54 FPS，3633帧。采样时绘制调用667→676，三角形820,186→1,242,686，几何体418→420、纹理97→97；三角形增加约51.5%，是精细车厢合入后的材料风险，本机结果不代表其他设备性能。
