# 验证报告索引

每个任务使用 [验证模板](../templates/validation-report.md)，报告命名 `<任务编号>.md`；复验可另存 `<任务编号>-<日期或序号>.md` 并互相引用，不覆盖历史证据。小修复也可在原报告追加新版本/环境与独立结论，避免混淆两次运行。
