## 行为与接口

- 插队、加塞、向 NPC 求助、与前面乘客协商等原始指导可以开放请求让位工具，符合用户对“和前面乘客商量”“向 NPC 求助”的追加说明。空白、单纯赶时间、逃票、一般闲聊及他人动作描述保持关闭；明确禁止优先。采用保守文本规则，复杂混合/含糊表达可能保持关闭。
- 两模型供应商均按原始指导提供工具和说明，拒绝返回未开放的工具调用；模型整理内容不能启用权限，整理结果中的未提及社交捷径不进入普通确认或模型指导。
- Runner 在构造时确定开关，阻止未允许的直接请求以及创造性行动绕行；拒绝结果不给出专用工具用法。NPC HTTP API 要求有效且有权限的会话，正文伪造允许标记无效。没有权限时不调用 NPC 模型、不改变位次。
- 获得权限后仍检查距离、可见性、NPC 是否排队、轮数和真实同意；原拒绝、失败、取消及迟到答复记录保持。Debug JSON 使用 `parameters.cutInEnabled` 保存本局开关；原始调用和实际结果照常留证。
- 内部 NPC 接口由可选会话改为必须绑定有权限的会话，旧无会话调用返回 403。页面 RemoteAgent 本来就传 sessionId；历史服务绑定、拒绝与用量测试显式建立获允许的会话。未更改难度、保安、服务时间或翻闸结算。
