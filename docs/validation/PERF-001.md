## 性能证据与边界

1. **优化前**：本机开发页面、seed 1、开局静止的 53 个角色场景，60 秒主动采样记录 7308 帧、121.8 FPS、P95 间隔 16.4ms。原来空闲画面也持续以显示器刷新率绘制。
2. **空闲按需绘制**：生产页面静止状态，诊断累计帧读数 5 → 7；中间仅操作两次轨迹开关以触发诊断刷新，未出现持续增加。开局、思考、暂停、终局停止渲染及 HUD 轮询；镜头、窗口变化、用户操作和显式性能采样仍会唤醒。
3. **简化乘客单项对照**：同一生产页面、53 个角色、标准画质、同一镜头及画布 741×1488 / DPR 1，仅切换简化乘客。每帧绘制调用 **572 → 184（减少约 67.8%）**，三角形 **28684 → 11784（减少约 58.9%）**。角色没有被删减；玩家、保安仍用完整几何角色，普通乘客保留位置与类型颜色。
4. **30 FPS**：最终生产构建、节能预设、暂停世界主动采样 19.61 秒 / 589 帧，**30.04 FPS**、P95 间隔 36.7ms；世界时间仍为 21.3 秒。继续运行并结束后，同一轮最终采样 **60.03 秒 / 1801 帧 / 30 FPS / P95 36.8ms**。限帧后的间隔是有意降低绘制频率，不能当成 GPU 计算时间或卡顿证据。

开发与生产的尺寸、DPR 和采样场景不同，不把两组 FPS 当作直接的硬件提速倍数；绘制调用对照只在同一个生产页面内进行。没有测量电池功耗、显存峰值、GPU 单帧耗时或低端硬件，不承诺相应百分比。

## 文件与函数职责

| 文件 | 函数及作用 |
|---|---|
| `src/ui/performanceSettings.ts` | `parsePerformanceSettings` 逐项校验存储数据并恢复安全默认值；`usePerformanceSettings` 读取/保存偏好、处理存储不可用、结合系统动效偏好；内部 `change` 同步系统动效变化 |
| `src/ui/PerformanceSettingsPanel.tsx` | `PerformanceSettingsPanel` 展示独立设置、节能预设及恢复默认；不接触模拟状态 |
| `src/ui/useGameSession.ts` | `useGameSession` 连接会话及 HUD；内部 `frame` 仅在运行时推进并按 120/500ms 刷面板，`changed` 即时刷新阶段并唤醒/停止循环，恢复时重置现实时间基准 |
| `src/ui/scene/GameScene.tsx` | `RenderSchedule` 管理按需帧调度，内部 `frame` 控制目标频率、`wake` 响应会话/可见性变化；`CameraRig` 插值与碰撞安全镜头，内部 `down/move/up/wheel` 处理拖动/缩放并唤醒静止画面；`GuardVision` 绘制调试视距；`DebugGround` 绘制可选轨迹/路径；`Contents` 组装场景与采样环境，内部 `lost` 处理图形上下文丢失；`GameScene` 建立按需 Canvas，画质切换时重建上下文以应用抗锯齿选项 |
| `src/ui/scene/SimpleCrowd.tsx` | `SimpleCrowd` 用两个实例批次绘制普通乘客，复用姿态对象和矩阵；不改变人数、模拟、观察或碰撞 |
| `src/ui/frameMetrics.ts` | `FrameMetrics.start` 重置采样，`push` 累计真实帧间隔并标记设置变化，`summary` 生成 FPS/P95 与环境快照；唤醒首帧休眠间隔由场景排除 |
| `src/ui/App.tsx` | `App` 接入保存的偏好、向会话传 HUD 间隔、向场景传画质/目标帧率/简化乘客参数；其他开局、模型、报告逻辑保留 |
| `tests/performanceSettings.test.ts`、`tests/frameMetrics.test.ts` | 覆盖损坏/未知偏好、预设保存和显式动效选择，以及采样期间设置变化的无效对照标记 |
